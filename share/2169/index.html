Claude Code: Contenedor seguro

Se ha identificado que ejecutar Claude Code en modo de permisos saltados directamente en la máquina host expone claves SSH locales, credenciales de API y archivos de repositorio a riesgos de inyección de comandos, por lo que se recomienda ejecutarlo en un contenedor seguro con firewall de salida para reducir un 99% las vulnerabilidades. La ejecución en un contenedor sandboxed con firewall de egress permite limitar el acceso a solo el directorio del proyecto montado en caso de una sesión comprometida.
