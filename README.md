# cYHBernews 🚀

A technology and cybersecurity newspaper with a premium iOS/macOS-inspired visual style.

## 🌐 Project

See the live site here:

👉 [https://devcop95.github.io/cYHBernews/](https://devcop95.github.io/cYHBernews/)

## ✨ Main Features

- **Premium interface:** A compact, minimal, and elegant design with glassmorphism and native blur effects.
- **Smart tools menu:** Real-time search, advanced sorting, and feed statistics.
- **Improved navigation:** The menu closes automatically after searches or filters, supports outside clicks, and can be closed with the Escape key.
- **Dynamic mesh gradient:** An animated high-performance background that creates a modern technology atmosphere.
- **Dynamic loading:** A JavaScript rendering engine that consumes `noticias.json` with versioned caching support.
- **News sections:** Automatic organization by date and category, including Current Affairs, Cybersecurity, Technology, and AI.
- **Fully responsive:** Optimized for desktop and mobile touch navigation.

## 🛠️ Technologies

- **Frontend:** Semantic HTML5 and advanced CSS3 using variables, Flexbox, Grid, and animations.
- **Logic:** ES6+ JavaScript with DOM manipulation, the Fetch API, and text normalization.
- **Icons:** Lucide Icons.
- **Typography:** Inter for the interface and Oswald for headlines, loaded through Google Fonts.

## 📁 Project Structure

- `index.html`: Main structure and UI components.
- `app.js`: Application orchestrator for state, data loading, filters, and events.
- `js/`: ES modules such as `utils.js`, `i18n.js`, `ui.js`, `stats.js`, `render.js`, and `modal.js`.
- `style.css`: Main styles, animations, themes, and responsive behavior.
- `noticias.json`: Static article database and source file used by the bot.
- `data/`: Derived frontend data files, including recent news, monthly archives, and the versioned manifest in `index.json`.

## ▶️ Run Locally

Because the project uses ES modules and the Fetch API, serve it through a local HTTP server instead of opening `index.html` directly with `file://`.

```powershell
py -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

The archive files in `data/` are regenerated by `scripts/split-news.js` through GitHub Actions whenever the bot updates the repository.
